# Dead Code Archaeology

In 1996, NASA lost the Mars Climate Orbiter because one team used metric units while another used imperial—a mismatch that went undetected until the spacecraft disintegrated in the Martian atmosphere. The code that performed the faulty conversion wasn't wrong in isolation; it was orphaned from its intended context, a dead pathway that nobody realized was still being traversed.

Software accumulates similar fossils. VisionSettings.tsx referenced a `visionAPI` that existed only in the component's imagination—twenty function calls to an interface that was never implemented, type errors screaming into a void that the build system politely ignored. PromptSettings.tsx awaited system prompts that would never arrive. These weren't failures of implementation but of deletion: someone built the backend, then removed it, leaving the frontend as a memorial. The cleanup we performed today wasn't writing new code but practicing what archaeologists call "stratigraphic excavation"—carefully removing layers to reveal what the system actually is, rather than what it once aspired to become. The 44 type errors we fixed were 44 lies the codebase was telling itself about its own capabilities.
