# Metered Transparency

In 1972, the Xerox Alto introduced the concept of "user illusion"—making the computer's complexity invisible behind intuitive metaphors. But there's a counter-principle that emerged from the cloud computing era: cost transparency. AWS's billing dashboard exists because hidden costs erode trust. When users don't see the meter running, they either overspend unknowingly or avoid features out of fear. Showing token counts transforms the auto-improve feature from a black box into an accountable tool.

The specific request—input tokens, output tokens, approximate cost—mirrors how Anthropic's own API console presents usage. Claude 3.5 Sonnet pricing ($3/million input, $15/million output as of early 2025) makes the math straightforward: `cost = (input_tokens * 0.000003) + (output_tokens * 0.000015)`. The implementation requires intercepting the API response's `usage` field, accumulating totals in persistent storage, and exposing them via IPC. It's not architecturally complex, but it touches multiple layers: the API caller, the preference store, and the settings UI. The value is in the signal it sends—we're not hiding costs, we're surfacing them.
