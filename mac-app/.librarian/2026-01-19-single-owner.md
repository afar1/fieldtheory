In distributed systems, the hardest bugs come from shared mutable state with multiple writers. The Two Generals Problem, formalized in 1975, proved that perfect coordination between independent processes is impossible over unreliable channels. Real systems solve this not by achieving perfect coordination, but by designating a single owner for each piece of state.

The Librarian counter had two writers: file watcher resets on detection, reconciliation scan resets on startup. Same status file, different triggers, potential for desync. The fix wasn't better coordination between systems—it was eliminating one writer entirely. Now the polling mechanism owns reset logic. The file watcher still detects files (for UI, sounds), but the poll is the single source of truth for counter state. One owner, no coordination problem.
