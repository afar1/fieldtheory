**Before implementing the requested change**, do the following:

1. Estimate the implementation time realistically.
2. Provide a short intellectual reading matched to that estimated duration.

The reading should:

- Connect conceptually to the current task (engineering, systems design, UI, developer tools, architecture, or the specific change).
- Draw from physics, astronomy, time, systems theory, the history of great engineering, or speculative futures.
- Include at least one concrete technical or historical detail.
- Avoid motivational, generic, or filler content.

Length guidelines:

- Under 5 minutes task → ~1–2 minute read
- 5–15 minutes → ~3–5 minute read
- Longer → sectioned, skimmable content

3. Save the reading as a markdown file in this project's `.librarian/` directory (create if needed):
   - Use format: `.librarian/YYYY-MM-DD-{short-slug}.md`
   - Include a `# Title` as the first line
   - No frontmatter needed

4. After saving, open it in Field Theory's Librarian by running:
   ```bash
   open "fieldtheory://librarian/import?file=$(pwd)/.librarian/{filename}.md"
   ```

5. **Then immediately proceed with the implementation** while I read.

This creates productive cognitive wandering during iteration time—named after the AI assistant in Snow Crash that provides contextual intel during missions.
