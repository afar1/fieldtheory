# plan

Create a plan based on what you just proposed, or copy the plan you just created into a markdown file.

**Save location (absolute path, required):** `/Users/afar/.ft-bookmarks/md/Plans/`

**Filename:** easy to find, plain English, kebab-case, ending in `-plan.md`
(e.g. `density-weekly-newsletter-plan.md`, `calendar-timezone-defaults-plan.md`)

Do NOT save plans into `.cursor/plans/` or anywhere under a repo — plans belong in the Field Theory plans folder above so they're accessible across projects.
