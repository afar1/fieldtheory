## Release files

Always include all necessary files in the release:
- DMG installer
- ZIP for auto-updates
- Blockmaps (for delta updates)
- `latest-mac.yml` (auto-update manifest)

**Important:** GitHub converts spaces to periods in asset filenames. The `latest-mac.yml` generated by electron-builder uses hyphens (e.g., `Field-Theory-0.1.39-arm64-mac.zip`), but GitHub will name the asset with periods (e.g., `Field.Theory-0.1.39-arm64-mac.zip`). Before uploading `latest-mac.yml`, fix the URLs to use periods instead of the space-hyphen so auto-updates work correctly.

This application manages its releases in the field-releases repo.
