# check-pr

this pr is from a user I don't know. first tell me in plain english the following:

1. what is the pr attempting to do? 
2. what does the user claim the pr is attempting to do and does this in any way differ from what it actually does
3. are there any security issues with either the users intent or their implementation. be suspicious.
3. is it worth doing (use your judgement). does it solve a real problem? Is it a worthwhile feature?
4. can the code be simpler, more elegant, or written in fewer lines? 
5. If we clear all of 1-4, then explain in plain english how you will re-write it and re-write the code and tell me how to test the feature or fix locally.

be sure to run refactor.md after you write any new code.
