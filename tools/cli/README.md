# ft

Field Theory CLI for recurring dataset review and improvement, powered by OpenClaw.

## Status
Early scaffold.

## Goals
- Define datasets (`repo`, `files`, `mixed`, later `bookmarks`)
- Schedule recurring runs via OpenClaw cron
- Persist state/artifacts in workspace files
- Treat X bookmarks as a first-class built-in source
- Keep repo-native memory via git notes when useful

## Planned commands
- `ft dataset ...`
- `ft job ...`
- `ft artifacts ...`
- `ft source ...`
- `ft bookmarks ...`
